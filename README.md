# 50 LLM Projects — daily worked implementations

One project per day from *50 ML Projects To Understand LLMs* by Mike X Cohen,
implemented from scratch and tested, based on the author's MIT-licensed companion code:
[mikexcohen/ML4LLM_book](https://github.com/mikexcohen/ML4LLM_book).

Each project folder contains its own scripts, tests, output plots, and a run screenshot.
No book text is reproduced here — code and results only.
